# Code of Conduct

Daily Adhkar welcomes contributors and readers of all backgrounds. Treat people with respect, give feedback about the work, and allow room for differences in language, experience, and scholarly opinion. When discussing religious sources, cite the relevant text and explain the proposed change.

Harassment, threats, slurs, personal attacks, sexualized comments, and publishing someone’s private information without permission are unacceptable. These expectations apply to issues, pull requests, reviews, and other project spaces.

Use GitHub’s **Report content** option for abuse or private information. Maintainers may remove content, limit discussions, or block accounts when necessary. GitHub can also review reports under its [Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines).
