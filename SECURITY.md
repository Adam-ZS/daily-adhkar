# Security Policy

Security fixes apply to the current version on the [GitHub Pages site](https://adam-zs.github.io/daily-adhkar/) and the source on `main`.

Report security issues privately using [GitHub’s vulnerability report form](https://github.com/Adam-ZS/daily-adhkar/security/advisories/new). Include the affected URL or commit, the browser and version, the observed impact, and enough detail for the maintainer to investigate. Remove credentials and personal information from attachments.

Please keep vulnerability details in the private report while a fix is being prepared. Use [GitHub Issues](https://github.com/Adam-ZS/daily-adhkar/issues/new/choose) for ordinary bugs and content corrections.
